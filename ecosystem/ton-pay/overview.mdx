TON Pay SDK is a developer toolkit for integrating checkout and transfer flows on the TON blockchain across React apps, backend services, and Telegram experiences.

<Aside type="caution">
  TON Pay is not a payment processor.
</Aside>

## Features

- Hosted React checkout through `TonPayWidget`
- Server-side transfer creation and explicit status lookups through `@ton-pay/api`
- TON and jetton payment flows
- Built-in on-ramp steps inside the widget when they are available for the current session

## UI integration

The default React integration is `TonPayWidget`.

It renders a merchant-facing button and opens a hosted widget that handles:

- session bootstrap
- checkout routing
- wallet logic
- on-ramp and top-up flows when available
- success and error callbacks

For most web applications, this is the fastest path to production. See [how to add a TON Pay widget using React](/ecosystem/ton-pay/ui-integration/button-react).

## Server-side integration

Use `@ton-pay/api` when the application needs:

- backend transfer creation
- explicit status lookups by `reference` or `bodyBase64Hash`
- MoonPay helper calls outside the hosted widget flow

See [server-side integration](/ecosystem/ton-pay/server-side-integration).

## How TON Pay works

1. The widget or backend prepares payment context.
1. The user reviews and confirms the transaction in the wallet flow managed by TON Pay or TON Connect.
1. The transaction is executed on TON.
1. TON Pay returns the result through widget callbacks or server-side lookup helpers, depending on the integration path.

## Security

- Non-custodial: funds remain under user control
- Standard protocols: built on TON standards and TON Connect
- Transparent: transactions remain verifiable on-chain
